# Autojen hallinta

React- ja Express-sovellus autojen listaamiseen, lisäämiseen, muokkaamiseen ja poistamiseen.

## Käynnistys

Asenna riippuvuudet ensimmäisellä kerralla:

```bash
cd harj_backend && npm install
cd ../harj_frontend && npm install
```

Käynnistä backend ja frontend omissa terminaaleissaan:

```bash
cd harj_backend
npm run dev
```

```bash
cd harj_frontend
npm run dev
```

Frontend toimii osoitteessa `http://localhost:5173` ja backendin API toimii osoitteessa `http://localhost:3001`.
